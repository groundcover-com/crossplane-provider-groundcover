Manage groundcover resources — monitors, dashboards, connected apps, and
notification routes — directly from Kubernetes with Crossplane. Write Kubernetes
manifests (kind: Monitor, Dashboard, ConnectedApp, NotificationRoute) and Crossplane
continuously reconciles them against the groundcover API.

Getting started: install this provider, create a ProviderConfig with your groundcover
API key, then apply your resource manifests.

Full docs and examples:
https://github.com/groundcover-com/crossplane-provider-groundcover
